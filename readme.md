# 💰 Personal Expense & Spending Analysis

A beginner-friendly Python project that analyzes personal expenses and helps understand spending patterns using basic Python data structures and operations.

## 📌 About the Project

The **Personal Expense & Spending Analysis** project was created as part of my Python learning journey.

The project uses a simple list of expenses and applies Python concepts such as:

* Lists
* Adding and inserting values
* Updating and removing values
* Loops
* Conditional statements
* Basic calculations
* Finding total and average expenses
* Analyzing spending patterns

The main goal is to build strong Python fundamentals before moving on to libraries such as **NumPy, Pandas, Matplotlib, and Streamlit**.

## 🎯 Objectives

* Store personal expenses using Python lists.
* Add and modify expense records.
* Calculate total spending.
* Find average spending.
* Identify higher and lower expenses.
* Practice basic data processing using Python.
* Build a foundation for future data-analysis projects.

## 🛠️ Technologies Used

* **Python**
* Python Lists
* Loops
* Conditional Statements
* Basic Functions and Calculations

## 🔍 Example Data

The project starts with sample expenses such as:

```python
expenses = [250, 100, 700, 600, 900]
```

The data can then be modified by adding or inserting new expenses.

Example:

```python
expenses.append(450)
expenses.insert(1, 300)
```
